# Burpsuite-learning-journey

## Overview

This repository documents my journey learning Burp Suite Community Edition while completing PortSwigger Web Security Academy labs.

The goal is to capture not only successful security assessments but also the troubleshooting, configuration challenges, and technical concepts required to build a functional web application testing environment.

## Topics Covered

- Proxy Configuration
- SSL/TLS Interception
- Certificate Management
- FoxyProxy Configuration
- HTTP Request Analysis
- Burp Repeater Workflow
- Web Application Testing Methodology

## Key Lessons

- Proper proxy orchestration
- Browser trust stores and CA certificates
- HTTP interception workflows
- Efficient use of Burp Suite Community Edition

## Labs Completed

- 30+ PortSwigger Labs
- SQL Injection
- IDOR/BOLA
- Access Control Testing
- Additional Web Security Topics
